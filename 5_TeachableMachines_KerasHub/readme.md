# Keras Hub and Teachable Machines

## 📌 Assignment Overview
This repository contains complete demonstrations of **Teachable Machines** and **Keras Hub** examples. The goal is to showcase various applications of **Teachable Machines (Google's framework)** and **Keras Hub models** by implementing small variations categorized as **easy, intermediate, advanced, and expert** levels.

### 1️⃣ **Teachable Machines Demos**
Implemented **three different examples** using **Teachable Machines**, covering text, image and video-based models.

- 🔹 **Text Classification Model**
  - A simple text-based classifier trained on custom categories.
  - Uses Teachable Machines' **Text Model** to classify different input text phrases.

- 🔹 **Image Recognition Model**
  - Trained on **custom image datasets**.
  - Explores fine-tuning and enhancing model accuracy using **transfer learning**.

- 🔹 **Video Gesture Recognition**
  - Uses Teachable Machines’ **Pose Model** for recognizing body gestures from video input.

---

### 2️⃣ **Keras Hub Model Implementations**
Explored **Keras Hub** models by implementing small variations of existing models. Each level (Easy, Intermediate, Advanced, Expert) consists of a separate Colab notebook.

| **Level**      | **Image Models**                           | **Text Models**                          |
|---------------|--------------------------------|--------------------------------|
| 🟢 Easy        | Pretrained model inference (e.g., MobileNet) | Sentiment classification (basic RNN) |
| 🟡 Intermediate | Fine-tuning a model (e.g., ResNet) | Text classification using BERT |
| 🔴 Advanced    | Custom CNN model trained from scratch | Transformer-based text processing |
| ⚫ Expert      | GANs for image synthesis | Custom LLM fine-tuning |
